Reference / Pi Wi-Fi

One connection,
in order

Identify USB adapter → load firmware → find network → associate → establish encryption keys → obtain DHCP address → use management.

TermMeaning here
DriverOur Rust code that configures a device and submits work to it.
FirmwareThe program loaded into the dongle’s internal processor.
BeaconA router announcement containing its network name and connection information.
AssociationThe exchange that establishes the station’s relationship with the access point.
WPA2Wi-Fi Protected Access 2; our Rust code performs its key exchange.
DHCPDynamic Host Configuration Protocol; assigns the IP address after the secure link is ready.
FrameBytes formatted for transmission over the Wi-Fi link.
UARTUniversal Asynchronous Receiver/Transmitter; our separate serial development and recovery connection.

Keep these two programs separate

Rust runs on the Pi. Realtek firmware runs on the dongle. The Pi performs the WPA2 exchange and runs DHCP; the dongle handles radio transmission and hardware packet encryption.

After reboot

The SD kernel repeats initialization and joins the configured network. DHCP can assign a different IP. The managed service answers mDNS queries for gabix-pi2.local, so your Mac can find its current address. Discovery implementation.
