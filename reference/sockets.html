UDP Socket Quick Reference

Objects, syscall contracts, delivery order, and blocking invariants for Lesson 26.

Core vocabulary

Socket
Kernel communication object holding protocol-facing state, queues, options, and errors.
Endpoint
One addressable end; an IPv4 UDP endpoint is an IP address and port.
Connection
Persistent transport state relating local and remote endpoints.
File descriptor
Process-local integer used to reach the socket object.

Constructor dimensions

Domain
Address format and protocol family: AF_INET, AF_INET6, or AF_UNIX.
Type
Application data contract: SOCK_DGRAM messages or SOCK_STREAM bytes.
Protocol
Concrete transport implementation, such as IPPROTO_UDP or IPPROTO_TCP.

Common lifecycles

UDP server: socket → bind → recvfrom ↔ sendto → close

TCP server: socket → bind → listen → accept → read/write → close

UDP connect: records a default peer and local receive filter; it performs no transport handshake.

Object ownership

Process FD table
fd → OpenObject::Socket(Arc<UdpSocket>). Grants access and controls lifetime.
Port table
local_port → Weak<UdpSocket>. Routes a received UDP datagram without keeping a closed socket alive.
UdpSocket
Bound endpoint, VecDeque<Datagram>, and waiting PID queue.
Datagram
Owned payload plus source IP address and source port.
Kernel network worker
Polls virtio RX, parses protocols, delivers to a socket queue, and wakes one blocked receiver for available work.

Syscall contracts

socket(AF_INET, SOCK_DGRAM, IPPROTO_UDP)
Create an unbound UDP socket; return the lowest free FD.
bind(fd, local, addrlen)
Validate FD and address; fail if the port already has a live binding.
recvfrom(fd, buf, len, flags, peer, peer_len)
Pop one datagram; copy at most len bytes and its sender endpoint; block when the queue is empty.
sendto(fd, buf, len, flags, peer, peer_len)
Copy user bytes, build one UDP datagram using the bound local port, and send it to peer.

Receive path

virtio RX → Ethernet → IPv4 protocol 17 → UDP destination port → port table → socket queue → wake PID → recvfrom → user buffer

Required invariants

  1. Queue check, waiter registration, and transition to Blocked form one atomic decision.
  2. UDP delivery owns the payload before the recycled RX buffer can change.
  3. Every user pointer and range is validated before copying.
  4. Socket locks are released before acquiring the global network-device lock for transmit.
  5. Closing the final FD removes or invalidates its port binding.

mini-os build target

/echo_server.elf binds 10.0.2.15:5555, receives one host-forwarded datagram, and sends the same bytes to the source endpoint returned by recvfrom.
