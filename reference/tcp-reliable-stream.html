Reliable send stream

Send positions

in_flight = send_next - send_unacked
usable_window = min(peer_window, 4 * MSS) - in_flight

send_unacked is the oldest unacknowledged byte. send_next is the sequence number assigned to the next byte transmitted. MSS means Maximum Segment Size.

Retained entry

{ sequence, flags, owned payload, sent_at tick, retransmitted }

Keep an entry until a cumulative acknowledgment number reaches its ending sequence. SYN and FIN add one to the ending sequence.

RFC 6298 estimator

first sample:
  SRTT   = sample
  RTTVAR = sample / 2

later samples:
  RTTVAR = 3/4 * RTTVAR + 1/4 * |old_SRTT - sample|
  SRTT   = 7/8 * SRTT   + 1/8 * sample

RTO = SRTT + max(clock_granularity, 4 * RTTVAR)

mini-os uses 10 ms ticks, a 1-second minimum RTO, and a 60-second maximum. A timeout doubles the current RTO.

Karn's algorithm

Discard a timing sample when its ACK covers a retransmitted segment. The ACK may correspond to the original transmission or the retransmission, so the elapsed time has no unique start point.
