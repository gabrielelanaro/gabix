UDP Quick Reference

Wire layout, length rules, checksum input, and the port-5555 echo path.

UDP datagram8 bytes + payload
source portu160–1SP
destinationu162–3DP
lengthu164–5LN
checksumu166–7Σ
payload[u8]8……
All four fields are big-endian. IPv4 protocol number: 17.

Parsing rules

  1. Require at least 8 bytes.
  2. Read udp_length; require 8 ≤ udp_length ≤ ipv4_payload.len().
  3. Expose payload as bytes 8..udp_length.
  4. Validate the checksum using source IP, destination IP, protocol 17, and UDP length.
  5. Use destination port to choose the receiver.

Checksum input

src_ip | dst_ip | 0 | 17 | udp_length | udp_header_with_zero_checksum | payload | optional_zero_pad

The optional zero byte participates only in calculation. For IPv4, a transmitted checksum of zero means checksum omitted. A calculated zero is transmitted as 0xffff.
