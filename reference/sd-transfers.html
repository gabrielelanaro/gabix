TermMeaning in this driver
SectorA numbered 512-byte block on the card.
RAM bufferThe kernel array holding the source or destination bytes.
MMIOCPU loads/stores to addresses that access device registers.
FIFOA controller buffer whose queued words are consumed in order.
PIOThe CPU copies each word between RAM and a controller register.
ClockA repeating electrical signal that provides timing.
PollingThe CPU repeatedly reads state until a condition changes.

Write sequence

CPU requests CMD24 for the sector → CPU feeds 128 four-byte words to DATA → controller sends the block → driver checks completion and CMD13 card status.

The source RAM pointer is used by the CPU. The destination sector number is sent to the controller. Source: sdhci.rs:143–197.

Clock arithmetic

SD clock = source clock / (2 × divider)
200 MHz / (2 × 1)   = 100 MHz       // Old invalid setting.
200 MHz / (2 × 4)   = 25 MHz        // Default-speed transfer limit.
200 MHz / (2 × 128) = 0.78125 MHz   // Temporary workaround.
200 MHz / (2 × 250) = 0.4 MHz       // Initialization limit.

The firmware query supplies the source rate. The driver rounds the divider up so its chosen clock does not exceed the requested limit. Source: set_clock.

Physical evidence and reproduction: Pi SD writes report. The 5.8× result concerns the measured 128-read sequence, including software overhead.
