Passive open and teardown

The server-side state and sequence rules implemented in Lesson 33.

Passive open

server                                      client
LISTEN       ← SYN seq=x
SYN_RCVD     SYN,ACK seq=y ack=x+1       →
ESTABLISHED ← ACK seq=x+1 ack=y+1

The listener remains in LISTEN. The kernel creates a connection object keyed by local address, remote address, local port, and remote port. accept() returns a descriptor for that object after the final ACK arrives.

Passive close

server                                      client
ESTABLISHED ← FIN,ACK seq=x
CLOSE_WAIT   ACK ack=x+1                 →
LAST_ACK     FIN,ACK seq=y               →
CLOSED      ← ACK ack=y+1

FIN consumes one sequence number. A read returns zero after the receive queue is empty and FIN has arrived. Closing a connection in CLOSE_WAIT sends the server FIN and waits for the final ACK in this implementation.
