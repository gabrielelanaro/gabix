DHCP Quick Reference

The DORA exchange, the inherited BOOTP layout, the options that matter, and the lease timers.

The exchange

1 · DISCOVERclient → broadcast 255.255.255.255:67 from 0.0.0.0:68. Fresh xid, chaddr = client MAC, BROADCAST flag set.
2 · OFFERserver → client. yiaddr = offered address, xid echoed. Options 53=2, 54 server id, 51 lease, 1 mask, 3 router, 6 DNS.
3 · REQUESTclient → broadcast (public acceptance). Option 50 = requested IP, 54 = chosen server. Unpicked servers reclaim their offers.
4 · ACKserver → client. Binding committed; parameters restated; lease clock starts. On failure: DHCPNAK → client restarts at DISCOVER.

BOOTP (RFC 951) header + magic cookie 0x63825363 + TLV options. All integer fields big-endian. UDP server port 67, client port 68.

Options (RFC 2132)

53 · message type
1 DISCOVER · 2 OFFER · 3 REQUEST · 4 DECLINE · 5 ACK · 6 NAK · 7 RELEASE · 8 INFORM
50 · requested IP
Client names the address it is accepting (REQUEST).
54 · server identifier
OFFER: who offers. REQUEST: who was picked.
51 · lease time
Seconds the address stays valid.
58 / 59 · T1 / T2
Renewal / rebinding timer overrides. Defaults: 0.5 × and 0.875 × lease.
1 / 3 / 6
Subnet mask, router, DNS server.
0 / 255
Pad / end of options.

Lease timers (RFC 2131 §4.4.5)

BOUND → T10.5 × lease. At T1: unicast REQUEST to the granting server (RENEWING).
T1 → T20.875 × lease. At T2: broadcast REQUEST to any server (REBINDING).
expiryAddress lost; client returns to INIT and starts at DISCOVER.

Client states

INIT → SELECTING → REQUESTING → BOUND → RENEWING → REBINDING, plus INIT-REBOOT for the remembered-address shortcut: broadcast a REQUEST for the old address; ACK confirms it, NAK sends the client back to INIT.
