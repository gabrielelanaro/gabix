Active open and byte positions

The fields and state changes implemented in Lesson 31.

Handshake

client                                      server
CLOSED
SYN_SENT     SYN seq=x                  →
             ← SYN,ACK seq=y ack=x+1
ESTABLISHED  ACK seq=x+1 ack=y+1         →

SYN consumes one sequence number. A payload consumes one sequence number per byte. An acknowledgment value names the next byte the receiver expects.

Current limits

One global TCP Control Block stores one active connection. The sender emits one bounded segment. There is no retransmission, sliding window, passive open, or teardown yet.
