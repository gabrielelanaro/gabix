The CS value encodes both the index and the ring: CS = index × 16 + ring. So kernel CS = 0x08 (index 1, ring 0), user CS = 0x1B (index 3, ring 3).

TSS (Task State Segment)

RSP00xffff_ffff_8001_0000

The TSS is a CPU structure that tells the CPU where the kernel stack is. When an interrupt fires while running user code (CPL=3), the CPU reads RSP0 from the TSS and switches to that stack before running the handler. Without this, the kernel would have no stack to use.

Real kernel pattern: iretq for the first kernel → user transition, syscall/sysret for the hot path (frequent syscalls), iretq for returning from hardware interrupts.
