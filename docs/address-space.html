Address Space: process switch vs kernel transition

Two processes (A and B) each have their own PML4 (Page Map Level 4 — the root of the 4-level paging tree) sitting in memory. The CPU's CR3 register points at whichever one is currently active. The kernel half of every PML4 (entries 256-511) points at the same shared kernel page tables; the user half (entries 0-255) is per-process.
