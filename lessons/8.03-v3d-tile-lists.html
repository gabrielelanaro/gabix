What turns a clear into a triangle?

Start with the blue clear from lesson two. Keep the same color and draw the triangle. Before the first gold pixel exists, V3D has already written something useful to RAM. What could it be?

Binning answers “which primitives might touch this tile?” Rasterization later answers “which samples in the tile do they cover?” On a larger image one triangle can appear in several tile lists. Our single tile keeps both stages visible with just one list to follow. Linux VC4 · rendering tile lists

Decode the draw packet

The compiled bytes start 21 04 03 00 00 00 00 00 00 00. Read them as opcode, primitive mode, a 32-bit count of three, and a 32-bit first-vertex index of zero. The next byte, 04, is a new packet that flushes binning.
