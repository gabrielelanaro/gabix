Inside the Pi’s VideoCore IV graphics hardware

How does a Rust driver get a separate piece of silicon to draw? Follow one triangle from the CPU’s first request to the finished image in RAM. Begin with the hardware diagram inside lesson one. Each lesson then isolates one part of that machine.

  1. How the Pi’s CPU talks to its GPU

    Locate the CPU that runs the driver and trace one register read to the device that answers.

  2. How can a Rust write start hardware?

    Follow a command from RAM to the executor. Predict what happens when the driver writes the end address.

  3. Why divide the job into two passes?

    Mark the tiles touched by one triangle and use their lists to reconstruct the work for one tile.

  4. Who runs a shader, and who sets up its inputs?

    Change a shader’s color. Predict which parts of the image change and which hardware determines the outline.

  5. What does parallel mean inside one QPU?

    Trace one instruction across sixteen input values using four physical lanes.

  6. Why does V3D need several kinds of memory?

    Track a vertex, a shader result and a stored tile. Identify which memory the next consumer reads.

  7. When can the ARM use the finished image?

    Trace the last tile into main memory. Explain how the CPU discovers completion and reads the new bytes.
