These numeric addresses come from the linked probe used on boot 32. The linker fixes the ARM entry at 0x00e00000. Offsets inside the image can move when you rebuild it. The names beside the addresses let you follow the next build too. Probe linker script

Start DMA channel 5

The first write puts the control block’s bus address in CONBLK_AD at 0x3f007504. The second writes 0x10000001 to CS at 0x3f007500. Bit 0 starts the channel. Bit 28 requests that outstanding writes complete before the transfer ends.
