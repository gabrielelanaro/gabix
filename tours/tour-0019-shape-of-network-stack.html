19.1Attach the card in QEMU

Files: tests/common.sh, scripts/run.sh

Both QEMU launch paths now add a user-mode network backend and a modern virtio-net PCI device. The UDP port forward is for the later echo-server milestone.

tests/common.shQEMU device flags
-netdev user,id=n0,hostfwd=udp::5555-:5555
-device virtio-net-pci,netdev=n0,disable-legacy=on,disable-modern=off

The modern-only flag makes the PCI device ID 0x1041. That is virtio device type 1, network, plus the modern PCI offset 0x1040.

19.2Represent a PCI function

File: src/pci.rs

A PCI function is named by three small numbers: bus, device, and function. PciDevice packages those numbers so callers can pass one value around.

src/pci.rsPCI coordinates
pub struct PciDevice {
    pub bus: u8,
    pub device: u8,
    pub func: u8,
}

19.3Search for one virtio device ID

File: src/pci.rs

The new helper scans bus 0 and returns the first virtio device whose PCI device ID matches the caller's target.

src/pci.rsgeneric virtio finder
pub fn find_virtio_device(device_id: u16) -> Option<PciDevice> {
    for device in 0..32u8 {
        for func in 0..8u8 {
            let vendor_word = config_read(0, device, func, 0x00);
            let vendor_id = (vendor_word & 0xFFFF) as u16;
            let found_device_id = (vendor_word >> 16) as u16;

            if vendor_id == 0x1AF4 && found_device_id == device_id {
                return Some(PciDevice { bus: 0, device, func });
            }
        }
    }
    None
}

The block helper still accepts the older block ID used by QEMU's existing disk path. The network probe uses the modern ID directly.

19.4Print the network card during boot

File: src/main.rs

After the block device setup, boot asks for virtio-net device 0x1041. If it is present, the kernel prints its location and decodes its six BAR slots.

src/main.rsLesson 19 probe
match pci::find_virtio_device(pci::VIRTIO_NET_NON_TRANSITIONAL) {
    Some(dev) => {
        println!("[pci] virtio-net found at {:02x}:{:02x}.{} device={:04x}",
                 dev.bus, dev.device, dev.func, pci::VIRTIO_NET_NON_TRANSITIONAL);
        pci::print_bars(dev.bus, dev.device, dev.func);
    }
    None => println!("[pci] virtio-net not found on bus 0"),
}

The card is only discovered here. The driver does no feature negotiation and gives the card no buffers yet.
