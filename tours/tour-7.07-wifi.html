2. Run the security exchange

3. Install a packet-encryption key

Rust gives the dongle the key produced by the security exchange. The dongle’s encryption hardware then uses that key for packet data. Here, 4 selects a hardware key-table entry; 0 is the key identifier; ap is the router’s Wi-Fi address; pairwise holds the key bytes.

4. Specify how a packet should be sent

descriptor is the instruction block that precedes the frame bytes. The cipher field selects hardware encryption for a protected frame. The rate setting chooses the initial fixed 1 Mbps transmission mode.

targets/armv7/src/raspi2b/rtl8188cu.rs:653
        let cipher = if frame[1] & 0x40 != 0 { 3 << 22 } else { 0 };
        descriptor[4..8].copy_from_slice(&(0x00060000u32 | queue | cipher).to_le_bytes());
        let sequence = u16::from_le_bytes([frame[22], frame[23]]) >> 4;
        // The adapter assigns non-QoS sequence numbers across both queues.
        // HWSEQEN is in the sequence field; HWSEQ selects it in control word 4.
        descriptor[14..16].copy_from_slice(&(sequence | 0x8000).to_le_bytes());
        descriptor[16..20].copy_from_slice(&0x180u32.to_le_bytes()); // HW sequence, CCK1.
        if data_frame {
            // Match the reference driver's data/RTS rate fallback limits.
            descriptor[20..24].copy_from_slice(&0x0001ff00u32.to_le_bytes());

What we verified

The physical Pi completed WPA2, obtained an address, and echoed data. It then disconnected and established a fresh connection. The managed kernel was uploaded over Wi-Fi, stored on SD, and booted after a remote reboot.

Recorded hardware results

Group-key replacement has host test vectors. A router-triggered group-key change and a full access-point outage still need physical checks.

Which parts also apply to x86?

The frame and WPA2 parsers live in crates/kernel-core/src/net/. The Realtek adapter code and Pi USB controller live under targets/armv7/. The tested x86 network device is VirtIO; it does not use this USB dongle path. Porting the radio to x86 would require USB-controller support there.
