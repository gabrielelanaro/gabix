12.1 Extend Superblock with two more fields

Files: src/ext2.rs

Two fields needed for the inode lookup math:

src/ext2.rs— two new Superblock fields
pub struct Superblock {
    // ... existing fields ...
    pub inodes_per_group: u32,  // NEW — offset 40
    pub inode_size:       u16,  // NEW — offset 88
}

On our disk: inodes_per_group = 128, inode_size = 256 (modern mkfs default; not the 128-byte spec minimum).

12.2 + 12.3 BlockGroupDescriptor + reader

Files: src/ext2.rs

32-byte struct, 6 fields parsed. Same pattern as Superblock.

src/ext2.rs— BlockGroupDescriptor
pub struct BlockGroupDescriptor {
    pub block_bitmap:      u32,  // offset 0
    pub inode_bitmap:      u32,  // offset 4
    pub inode_table:       u32,  // offset 8 — LOAD-BEARING
    pub free_blocks_count: u16,  // offset 12
    pub free_inodes_count: u16,  // offset 14
    pub used_dirs_count:   u16,  // offset 16
}

The reader computes the byte offset (bgdt_block × block_size + group × 32) and reads the containing sector.

12.4 + 12.5 Inode parser + reader + verify inode 2

Files: src/ext2.rs, src/main.rs

128-byte inode struct, 11 fields parsed including all 15 block pointers.

src/ext2.rs— Inode struct (key fields)
pub struct Inode {
    pub mode:           u16,         // 0x00 — file type + perms
    pub uid:            u16,         // 0x02
    pub size:           u32,         // 0x04 — file size in bytes
    pub atime:          u32,         // 0x08
    pub ctime:          u32,         // 0x0C
    pub mtime:          u32,         // 0x10
    pub dtime:          u32,         // 0x14
    pub gid:            u16,         // 0x18
    pub links_count:    u16,         // 0x1A
    pub blocks:         u32,         // 0x1C — in 512-byte sectors!
    pub block_pointers: [u32; 15],    // 0x28 — 12 direct + ind + 2x + 3x
}

Helper methods decode the file type via masking:

pub fn file_type(&self) -> u16 { self.mode & S_IFMT }  // top 4 bits
pub fn is_dir(&self) -> bool { self.file_type() == S_IFDIR }
pub fn is_reg(&self) -> bool { self.file_type() == S_IFREG }

read_inode walks the math:

src/ext2.rs— the lookup arithmetic
let local_idx  = (inode_num - 1) % sb.inodes_per_group;
let inode_byte = bgd.inode_table as u64 * sb.block_size as u64
               + local_idx as u64 * sb.inode_size as u64;
// For inode 2: 8 * 1024 + 1 * 256 = 8448
