TCP reliable stream

Retain sent bytes, advance a cumulative acknowledgment, and retransmit the oldest expired segment.

Core src/net/tcp.rs Timer owner net-rx Proof tests/test_tcp_reliable_stream.sh

A TCP segment can disappear after the sending application has returned from send(). The kernel must retain the segment's bytes and sequence number until an ACK covers them. Lesson 32 adds that retained state, measures elapsed timer ticks for fresh acknowledgments, and transmits the oldest retained segment again when its timer expires.

32.1Each retained entry contains everything required to rebuild a segment

RetransmitEntry owns the payload because the user buffer may change after the syscall returns. sequence_end computes the first sequence number after the entry. SYN and FIN each consume one sequence number; payload consumes one sequence number per byte.

src/net/tcp.rs— retained outbound segment
#[derive(Clone)]
struct RetransmitEntry {
    sequence: u32,
    flags: u8,
    payload: Vec<u8>,
    sent_at: usize,
    retransmitted: bool,
}

impl RetransmitEntry {
    fn sequence_end(&self) -> u32 {
        self.sequence
            .wrapping_add(self.payload.len() as u32)
            .wrapping_add(((self.flags & (FLAG_SYN | FLAG_FIN)) != 0) as u32)
    }
}

retain_for_ack copies every SYN or data segment into the queue at its first transmit tick. The active-open path therefore applies the same timeout machinery to the handshake SYN and application bytes.

32.2The send loop stays inside two byte limits

send_data subtracts current in-flight bytes from the smaller of the peer's advertised window and mini-os's fixed four-segment congestion limit. It splits the accepted prefix at the Maximum Segment Size (MSS), retains each chunk, advances send_next, and returns all segments to the syscall.

src/net/tcp.rs— sliding-window send calculation
let in_flight = tcb.send_next.wrapping_sub(tcb.send_unacked) as usize;
let window = core::cmp::min(
    tcb.send_window as usize,
    CONGESTION_WINDOW_SEGMENTS * SEND_MSS,
);
let allowed = window.saturating_sub(in_flight).min(payload.len());

for chunk in payload[..allowed].chunks(SEND_MSS) {
    let sequence = tcb.send_next;
    let segment = build_at(tcb, sequence, FLAG_PSH | FLAG_ACK, chunk)?;
    retain_for_ack(tcb, sequence, FLAG_PSH | FLAG_ACK, chunk);
    tcb.send_next = tcb.send_next.wrapping_add(chunk.len() as u32);
    outbound.push(segment);
}

The normal MSS is 1460 bytes. The Lesson 32 test uses 12 bytes so the 31-byte DNS query produces three segments and exercises the loop on a short exchange.

32.3A cumulative ACK removes every covered entry

An acknowledgment number names the next byte the peer expects. acknowledge removes every entry whose ending sequence is at or below that number, assigns the number to send_unacked, and reports the remaining queue length.

src/net/tcp.rs— cumulative acknowledgment
tcb.retransmit_queue.retain(|entry| {
    if entry.sequence_end() <= acknowledgment {
        if entry.retransmitted {
            acknowledged_retransmission = true;
        } else {
            sample = Some(now.saturating_sub(entry.sent_at));
        }
        false
    } else {
        true
    }
});
tcb.send_unacked = acknowledgment;

If the ACK covers a retransmitted entry, its timing is ambiguous. The function discards the timing sample according to Karn's algorithm. A fresh ACK feeds its elapsed ticks into the round-trip-time estimator.

32.4The estimator converts samples into a retransmission timeout

RttEstimator stores smoothed round-trip time (SRTT), round-trip-time variation (RTTVAR), and the current RTO in 100 Hz timer ticks. The first sample initializes SRTT and RTTVAR. Later samples apply the integer form of the RFC 6298 weighted averages. mini-os clamps the RTO to a 1-second minimum and a 60-second maximum.

src/net/tcp.rs— RFC 6298 update
let deviation = old_srtt.abs_diff(sample);
self.rttvar_ticks = (3 * self.rttvar_ticks + deviation) / 4;
self.srtt_ticks = Some((7 * old_srtt + sample) / 8);

let variation = (4 * self.rttvar_ticks).max(CLOCK_GRANULARITY_TICKS);
self.computed_rto_ticks = self.srtt_ticks.unwrap_or(sample)
    .saturating_add(variation)
    .clamp(INITIAL_RTO_TICKS, MAX_RTO_TICKS);

32.5The network task checks the oldest deadline every timer tick

The timer interrupt wakes net-rx at 100 Hz. After the task drains received frames, it calls poll_retransmit. An expired entry receives a new send tick and a retransmission marker. The estimator doubles the current RTO, and build_at rebuilds the segment with its original sequence number.

src/virtio.rs— receive drain and timeout transmission
while device.poll_rx().is_some() {}
if let Some(outbound) =
    crate::net::tcp::poll_retransmit(
        crate::interrupts::TICKS.load(Ordering::Relaxed))
{
    let _ = device.send_ipv4_packet(
        crate::net::ipv4::PROTOCOL_TCP,
        outbound.dst_ip,
        &outbound.bytes,
    );
}

The interrupt handler increments the tick counter and wakes the task. TCP parsing, locking, segment construction, and device transmission execute in task context.

32.6The end-to-end test removes one segment before device transmission

The test-only branch returns success for the first data segment without passing it to virtio-net. The second and third segments reach slirp first. Slirp keeps them out of order and waits for the missing sequence range.

Current boundary

The sender retains and retransmits SYN and payload segments for one active connection. It accepts an application-buffer prefix that fits the current window. It uses one timer for the oldest entry and a fixed congestion limit. Out-of-order receive buffering, fast retransmit, adaptive congestion control, connection tables, passive open, and teardown remain outside this implementation.
