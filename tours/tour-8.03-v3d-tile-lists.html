Binning and rendering in Gabix

Trace the branch that distinguishes a clear from a draw. The same render list can perform both.

Build work for one tile

The binning configuration describes a one-by-one tile grid. The draw packet supplies a vertex count of three and starting index of zero. The flush finishes the generated lists.

Use the tile list

Opcode 17 branches to a sublist. The clear-only path replaces its five bytes with no-operations. Opcode 25 stores the tile and signals frame completion. Follow the Rust submission order to see when each list is safe to use.

Check against the board
