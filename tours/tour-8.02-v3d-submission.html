Starting V3D in Gabix

Follow one byte from the Mac’s command line to the ARM function that reads V3D. Then follow the same function when you ask it to render the triangle’s blue background.

On the Mac, build and call the probe

These are the two commands for the ID experiment. Run them from the Gabix checkout with the Pi booted into the Wi-Fi development kernel. The first compiles v3d.rs into ARM instructions. The second uploads that image into Pi RAM, sends a run request and prints the result. ARM build · Client entry point

sh scripts/build-pi2-ram-probe.sh \
  targets/armv7/probes/v3d.rs target/probes/v3d.img
python3 scripts/pi2-ram-probe.py \
  --image target/probes/v3d.img --input-hex 00

The printed session number identifies the copy in Pi RAM. The next output line is 56334402. Python converted the two hex digits 00 into one byte. Its outer message says RUN, which Gabix understands. The single byte inside is an argument to our Rust function. Parse the argument · Send RUN

On the Pi, Gabix makes a function call

entry points at the start of the uploaded program in RAM, 0x00e00000. The linker placed probe() there. In this call the input pointer leads to 00, the input length is one byte, and the output pointer leads to space reserved by Gabix. The ARM executes probe() with the kernel’s privileges. Entry address · Type of the function

On the ARM, check power and read the ID

When V3D needs power, the ARM asks the Raspberry Pi firmware running on VideoCore to enable domain 11. The request travels through the hardware mailbox. Once V3D is ready, the ARM reads its ID register directly. Write the request address to the mailbox · Read a device register

On a clear request, start V3D’s render list

The next call supplies 01 96 42 19 ff. The ARM places that color in the command list, then calls submit(RENDERING, …). RENDERING equals 1, so thread * 4 adds four bytes. The two ARM register addresses are 0x3fc00114 for the start and 0x3fc0010c for the end. V3D starts fetching from RAM on the end write. Copy the color · Submit the render list
