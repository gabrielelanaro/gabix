What to look for

Task A is running with r0 = 10. A timer interrupts it, and task B runs with r0 = 99. When A resumes, it needs its original 10. Follow where that value is stored while B uses the CPU.

The model also tracks the Z flag: a bit set to 1 when a comparison finds equal values. A has just compared 10 with 10, so Z is 1. Its next instruction branches if Z is 1. Both the number in r0 and the comparison result must survive the interruption.

PC and SP
The program counter identifies the code being executed. The stack pointer identifies the current stack position.
SVC and IRQ modes
Our kernel tasks run in SVC mode. A timer interrupt enters IRQ mode. ARM has separate stack pointers and link registers for these modes; changing modes selects those registers.

Check the two different restores

When the dispatcher selects A again, A first resumes inside yield_now(). At that point r4 holds the wrapper’s saved frame address. Later, the IRQ wrapper restores A’s interrupted r4 value, 40. These restores happen at different points because the handler itself was paused while B ran.

Use Previous to find both operations. Identify the stack group consumed by each one. Then explain why restoring only the switch context would leave A’s original calculation unfinished.

Check your explanation

The switch context resumes the suspended handler call. The handler must still return through the IRQ wrapper, which restores the interrupted general-purpose registers and then the interrupted PC and status. Only after those operations can A continue its original instruction sequence.

What the model includes

The instruction sequence follows boot.S, context.rs, and scheduler.rs. Step labels distinguish hardware behavior, assembly, and grouped Rust calls.

This is a model of one possible execution, not an ARM instruction emulator or a live view of the Pi. Code addresses and stack positions are symbolic. r0, r4, and Z have chosen example values. The other general-purpose registers, compiler-generated call frames, stack-alignment padding, and dispatcher stack are grouped or omitted. Floating-point registers and userspace scheduling are outside this lesson.

The physical kernel test uses two non-yielding tasks that exchange progress counters. This lesson uses a comparison and branch so you can see why register values and condition flags both need restoration.
