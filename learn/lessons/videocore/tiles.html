Why divide the job into two passes?

A tile is a rectangular region of an image. On this six-tile sketch, a triangle crosses some regions and misses others. Pick the tiles that should receive work.

The two submissions for our triangle · v3d.rs, line 267

if mode == 2 && !submit(BINNING, addr_of!(bin_list), addr_of!(bin_end)) {
    return stop_stalled_job(-20);
}
if !submit(RENDERING, addr_of!(render_list), addr_of!(render_end)) {
    return stop_stalled_job(-21);
}

In this snippet mode 2 means draw a triangle. The other rendering experiment just clears the frame to a solid color. The real Gabix frame is 64 × 64 and fits in one tile with its chosen format. The six-tile sketch enlarges the problem to make the reason for binning visible. Broadcom guide · p. 46
