spawn(entry)
Allocate one of four fixed task slots and construct its initial saved stack.
run_until_finished()
Scan ready tasks in slot order and resume each. Return when none remain ready.
yield_now()
Mark this task Ready, save its registers, and restore the dispatcher.
Task return
The entry trampoline marks the task Finished and restores the dispatcher.
Saved ARM integer context
r4–r11 and lr on each task’s stack; sp in TaskContext.
Timer preemption
The IRQ wrapper saves interrupted state on the task’s SVC stack. After acknowledging the timer, preempt_on_timer calls yield_now. Scheduler updates run with IRQs masked. See lesson 3.06.
Limits
Single core, shared kernel memory, integer-only context. Cooperative yields and timer-driven preemption; blocking remains future work.
