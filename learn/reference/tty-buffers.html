TTY buffers and wakeup

Lesson 4.11: interactive walkthrough and sources

Canonical input

UART or PTY → kernel line discipline → unfinished edit area → newline commits readable input → read copies bytes to the process.

Noncanonical editor

UART or PTY → kernel readable bytes → read → user editor buffer → Enter submits the command to the parser. Kernel echo can be disabled so the editor draws the line.

Sleep and wake

Check readiness and register the waiter with a coordinated protocol. Input completion wakes a blocked task. Ready means eligible for scheduling. Once scheduled, the read handler rechecks input, copies bytes and returns a count.

Terms

TTY
Kernel terminal interface, historically named for the teletype.
PTY
Master/slave virtual terminal pair connecting an emulator and a terminal-reading process.
Line discipline
Kernel input/output processing, including canonical editing and echo.
Controlling terminal
Terminal associated with a session, with a foreground process group for job control.
