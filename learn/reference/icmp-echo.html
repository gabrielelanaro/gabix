Constants

IPv4 protocol
1 — ICMP.
Echo request
type = 8, code = 0.
Echo reply
type = 0, code = 0.
Checksum
RFC 1071 one’s-complement checksum across the full ICMP message, checksum field zero during calculation.
Byte order
Identifier, sequence, and checksum are big-endian.

Reply acceptance rule

  1. IPv4 source equals GATEWAY_IP (10.0.2.2); destination equals OUR_IP (10.0.2.15).
  2. IPv4 protocol equals 1.
  3. ICMP message is at least eight bytes, has a valid checksum, type 0, and code 0.
  4. Identifier, sequence, and payload equal the pending request.

QEMU proof target

QEMU user-mode networking uses 10.0.2.15 for the guest and 10.0.2.2 for its local router. QEMU documents that ping to the local router works. The implemented test_icmp_ping.sh fixture sends four requests with identifier 0x2400, sequences 7..10, and payload mini-os, then requires every matching reply.

Reply to an inbound request

Copy identifier, sequence, and payload; change type 8 → 0; recompute the ICMP checksum; reverse the IPv4 source and destination addresses; rebuild the IPv4 checksum; transmit through the existing ARP-backed path.
