Start the two control threads

V3D registers begin at ARM physical address 0x3fc00000. A control thread is a hardware command reader. Thread 0 performs binning and thread 1 performs rendering. A write to a thread’s end-address register starts it when work is available. Driver submission · Broadcom · tables 48–51

Decode one vertex in RAM

At 0x00e01080 the bytes 00 02 80 00 encode X = 0x0200 and Y = 0x0080. Divide each by 16 for screen coordinates (32, 8). The shader record gives a stride of 24 bytes, so the second vertex starts at 0x00e01098. Stride and addresses · Vertex words

Read a QPU register operation

A QPU instruction is 64 bits. ldi r3, 0xffffcd28 loads the packed gold constant into a QPU accumulator. mov tlbc, r3 writes that accumulator to the tile-color destination. That destination uses coordinates and coverage supplied to this fragment thread. The scoreboard wait orders access to tile storage. QPU instruction words · Broadcom · QPU tile-buffer access
